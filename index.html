❓ 不知道怎麼取得 API Key？
  1. 前往 Google AI Studio API Keys 頁面
  2. 登入 Google 帳號後，點「Create API key」
  3. 選擇或建立一個 Google Cloud 專案（免費）

Key 只需要設定一次，下次開啟會自動記住。
⚠️ 若你的 Key 是 2025 年以前申請的，Google 將於 2026 年 9 月停用舊版 Key，屆時請重新申請新版 Key。
步驟截至 2026 年 6 月有效，如介面有變動請搜尋「Google AI Studio API Key」。
