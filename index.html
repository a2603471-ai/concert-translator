❓ 不知道怎麼取得 API Key？
  1. 前往 Google AI Studio API Keys 頁面
  2. 登入 Google 帳號後，點「Create API key」
  3. 選擇或建立一個 Google Cloud 專案（免費）
  4. 複製產生的 Key，貼到上方欄位
Key 只需要設定一次，下次開啟會自動記住。
⚠️ Google 已停用舊版「AIza 開頭」的 Key，請使用新版「AQ. 開頭」的 Key。
🔒 建議在 AI Studio 把 Key 限定只能用 Gemini API，並設定每月花費上限，萬一外洩損失有限。
步驟截至 2026 年 11 月有效，如介面有變動請搜尋「Google AI Studio API Key」。
